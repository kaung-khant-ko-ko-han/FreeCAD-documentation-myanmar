# ဖရီးကက် (FreeCAD) စာတမ်းများ

**မှတ်ချက်**: ဤသိုလှောင်ရုံ၌ https://wiki.freecadweb.org တွင်တည်ရှိသော ဖရီးကက် ဝီကီကို [markdown ပုံစံ](https://en.wikipedia.org/wiki/Markdown) သို့ အလိုအလျောက် ပြောင်းလဲထားပါသည်။ ပြောင်းလဲရေးလုပ်ငန်းကို ဤသိုလှောင်ရုံအတွင်းရှိ [migrate.py](./migrate.py) စကရစ်ဖြင့် အလိုအလျောက် ဆောင်ရွက်ထားပါသည်။ စကရစ်သည် MediaWiki API ကို အသုံးပြု၍ ဝီကီအကြောင်းအရာများကို XML ပုံစံဖြင့် ဒေါင်းလုတ်ဆွဲပြီး [pandoc](https://pandoc.org/) ဖြင့် MediaWiki နှင့် markdown ပုံစံများအကြား ပြောင်းလဲပါသည်။ ဤလုပ်ငန်းသည် ဖရီးကက်အတွက် အသုံးဝင်ပြီး ထည့်သွင်းသယ်ဆောင်နိုင်သော စာတမ်းများကို တိုးတက်စေရန် ရည်ရွယ်ထားသည့် စီမံကိန်းတစ်ခု ဖြစ်ပါသည်။ ဤစာတမ်းများကို ဖရီးကက်၏ [Help module](https://github.com/yorikvanhavre/FreeCAD-Help) မှ အသုံးပြုနိုင်ပါသည်။

ဤစာတမ်းများကို ဖရီးကက် [addons manager](wiki/Std_AddonMgr.md) မှတဆင့် အော့ဖ်လိုင်း၌ ထည့်သွင်းပြီး ဖတ်ရှုနိုင်ပါသည်။

## နိဒါန်း

ဤသည်မှာ [ဖရီးကက် (FreeCAD)](http://www.freecadweb.org) ၏ တရားဝင် စာတမ်းများဖြစ်ပါသည်။ ဤစာတမ်းများကို အသုံးပြုနိုင်ခြင်းအနေနှင့် များသောအားဖြင့် hub များကို ရှာဖွေခြင်း၊ လက်စွဲစာအုပ် (manual) ကို လိုက်နာဖတ်ရှုခြင်း သို့မဟုတ် သတ်မှတ်စာမျက်နှာတစ်ခုကို ရှာဖွေခြင်းတို့ဖြင့် လွယ်ကူစွာ အသုံးချနိုင်ပါသည်။ ဖရီးကက်တွင်ပါသော Help menu ကဏ္ဍမှ လည်း ဤစာတမ်းများကို အွန်လိုင်း သို့မဟုတ် အော့ဖ်လိုင်းနှစ်မျိုးစလုံးဖြင့် ဖတ်ရှုနိုင်ပါသည်။ ဤစာတမ်းများသည် ဖရီးကက် အသုံးပြုသူများနှင့် ဖွံ့ဖြိုးသူများ၏ အဖွဲ့အစည်းမှ ရေးသားထောက်ပံ့နေသည့် တိုးတက်ဆဲ အလုပ်တစ်စိတ်ပင်ဖြစ်သည်။ မမှန်ကန်သော်လည်း သို့မဟုတ် လက်လွတ်နေသည့် အချက်အလက်များကို တွေ့ရှိပါက ကျေးဇူးပြု၍ [ကူညီလိုက်ပါ](Special:MyLanguage/help_FreeCAD.md)။

## hubs များ

#### <img alt="Crystal_Clear_app_display.png" src=wiki/images/Crystal_Clear_app_display.png  style="width:32px;"> [အသုံးပြုသူ hub](wiki/User_hub.md)

ဤစာမျက်နှာတွင် ဖရီးကက်အသုံးပြုသူများအတွက် အသုံးဝင်သော စာတမ်းများကို စုစည်းထားပါသည်။  
[မကြာခဏ မေးမြန်းကြသော မေးခွန်းများ](wiki/Frequently_asked_questions.md),  
[လုပ်ငန်းခွင်များ (Workbenches)](wiki/Workbenches.md) အားလုံးစာရင်း,  
ဖရီးကက် အက်ပလီကေးရှင်းကို [ထည့်သွင်းခြင်း](wiki/Installing.md) နည်းလမ်းများနှင့် အသုံးပြုပုံများ,  
[သင်ခန်းစာများ](wiki/Category_Tutorials.md),  
[ကိရိယာများ (List of Commands)](wiki/List_of_Commands.md) နှင့် ကိုးကားစာရင်းများ၊  
နှင့် စတင်အသုံးပြုရန် လိုအပ်သည့် အချက်အလက်များအားလုံး ပါဝင်ပါသည်။

#### <img alt="" src=wiki/images/Crystal_Clear_app_terminal.png  style="width:32px;"> [အဆင့်မြင့်အသုံးပြုသူ hub](wiki/Power_users_hub.md)

ဤစာမျက်နှာတွင် အဆင့်မြင့်အသုံးပြုသူများနှင့် [Python](https://python.org) ကုဒ်ရေးသားလိုသူများအတွက် စာတမ်းများကို စုစည်းထားပါသည်။ မက်ခရိုများ၏ သိုလှောင်စနစ် ([macros](wiki/Macro.md))၊ ထည့်သွင်းအသုံးပြုပုံများ၊ [Python API](wiki/Category_API.md) စာတမ်းများ၊ ဖရီးကက်ကို ကိုယ့်လိုအပ်ချက်အရ စိတ်ကြိုက်ပြင်ဆင်ခြင်းနှင့် တိုးချဲ့ခြင်းဆိုင်ရာ အချက်အလက်များ လည်း ပါဝင်ပါသည်။

#### <img alt="" src=wiki/images/Crystal_Clear_app_tutorials.png  style="width:32px;">[ဖွံ့ဖြိုးသူ hub](wiki/Developer_hub.md)

ဤအပိုင်းတွင် C++/Python ဖြင့် ဖရီးကက် မူရင်းကုဒ်နှင့် အလုပ်လုပ်လိုသူ ဖွံ့ဖြိုးသူများအတွက် အချက်အလက်များ ပါဝင်ပါသည်။ ကိုယ့်ကိုယ်ကို [ဖရီးကက်ကို ကုဒ်ရေးဖန်တီးခြင်း](wiki/Compiling.md) နည်းလမ်းများ၊ မူရင်းကုဒ် အဖွဲ့အစည်းနှင့် လမ်းညွှန်မှုများ၊ လုပ်ငန်းခွင်အသစ်များ ဖန်တီးခြင်းနှင့် ကိုယ်ပိုင် အက်ပလီကေးရှင်းများထဲသို့ ဖရီးကက်ကို ထည့်သွင်းအသုံးပြုရန် လမ်းညွှန်ချက်များ စသဖြင့် ပါဝင်ပါသည်။

## လက်စွဲစာအုပ်

#### <img alt="" src=wiki/images/Crystal_Clear_manual.png  style="width:32px;"> [ဖရီးကက် လက်စွဲစာအုပ်](wiki/Manual_Introduction.md)

လက်စွဲစာအုပ်သည် ဤဝီကီတွင်ပါဝင်သော အချက်အလက်များကို ပိုမိုစနစ်တကျ စုစည်းဖော်ပြသည့် နည်းလမ်းဖြစ်သည်။ စာအုပ်တစ်အုပ်ကဲ့သို့ ဖတ်ရှုရန် ရည်ရွယ်ထားပြီး အထက်ဖော်ပြထားသော hub များမှ အခြားစာမျက်နှာများသို့ ပိုမိုလွယ်ကူစွာ ရွေ့လျား၍ ဖတ်ရှုနိုင်ပါသည်။ [ebook ဗားရှင်းများ](https://www.gitbook.com/book/yorikvanhavre/a-freecad-manual/details) နှင့် [PDF ဗားရှင်းများ](https://www.freecadweb.org/manual/) ကိုလည်း ရရှိနိုင်ပါသည်။

## အခြား စိတ်ဝင်စားဖွယ် ရင်းမြစ်များ

* [လှူဒါန်းမှု](wiki/Donate.md) အတွက် ရွေးချယ်စရာများ
* ဖရီးကက်သည် ၂၀၁၆ ခုနှစ်မှ စတင်၍ [Google Summer of Code](wiki/Google_Summer_of_Code.md) တွင် ပါဝင်ဆောင်ရွက်လာပါသည် — ပါဝင်ရန် နည်းလမ်းများကို လေ့လာနိုင်ပါသည်။
