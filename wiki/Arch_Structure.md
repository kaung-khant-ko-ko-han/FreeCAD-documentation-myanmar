# Arch Structure

## သရုပ်ဖော်ချက်

[Arch Structure](Arch_Structure.md) ကိရိယာသည် အကျယ်၊ အရှည်နှင့် အမြင့်များကို သတ်မှတ်ပေးခြင်းဖြင့် သို့မဟုတ် 2D ပရိုဖိုင် (မျက်နှာပြင်၊ ဝါယာ သို့မဟုတ် ပုံကြမ်း [Sketch]) ကို အခြေခံ၍ ကော်လံ (column) သို့မဟုတ် ဘီးမ် (beam) ကဲ့သို့သော ဖွဲ့စည်းမှု အစိတ်အပိုင်းများကို ဖန်တီးရန် အသုံးပြုနိုင်သည်။

ပရိုဖိုင်မရှိပါက အဆင်ပြေစွာ စံပုံစံ ပရိုဖိုင်များမှ အလျင်အမြန် ဖွဲ့စည်းမှု အစိတ်အပိုင်း တစ်ခုကို တည်ဆောက်ရန် အသင့်ဖြင့် ရရှိနိုင်သည့် preset များ ပါရှိသည်။

 <img alt="" src=images/Arch_Structure_example.jpg  style="width:400px;">  
*2D အခြေခံပရိုဖိုင်ကို အခြေခံထားသော ကော်လံတစ်ခု; အခြေခံပရိုဖိုင်မရှိ၍ အမြင့်၊ အရှည်နှင့် အကျယ်ဖြင့် သတ်မှတ်ထားသော ကော်လံနှင့် ဘီးမ်; 2D မျက်နှာပြင်ကို အခြေခံထားသော သံဖွဲ့စည်းမှုတစ်ခု*

## အသုံးပြုနည်း

1. 2D အရွက် (Draft object၊ မျက်နှာပြင် သို့မဟုတ် ပုံကြမ်း [Sketch]) တစ်ခုကို ရွေးချယ်ပါ (လိုအပ်လျှင်)။
2. မီနူးမှ **Utils → Structure tools → <img src="images/Arch_Structure.svg" width=16px> Structure** ကို ရွေးချယ်ပါ။
3. လိုချင်သော ပိုင်ဆိုင်မှုများကို စီမံညှိနှိုင်းပါ။

## ရွေးချယ်စရာများ

- အခြေခံ 2D အရာဝတ္ထု မရွေးချယ်ထားပါက Structure ကိရိယာတွင် ဆွဲရေးဆောင်ရွက်မှု မုဒ် ၂ မျိုး ရှိသည် — ကော်လံ (Column) နှင့် ဘီးမ် (Beam) မုဒ်များ။
    - ကော်လံ မုဒ်တွင် သင့်အား မျက်နှာပြင်ပေါ်မှ အချက်တစ်ချက်ကို နှိပ်ရန် သို့မဟုတ် ကိုဩဒိနိတ် (coordinate) များ ထည့်သွင်းရန် တောင်းဆိုပါမည်။ ဖန်တီးမည့် ဖွဲ့စည်းမှု အရာဝတ္ထုသည် အဆိုပါ အချက်တွင် တည်ရှိမည်။
    - ဘီးမ် မုဒ်တွင် သင့်အား မျက်နှာပြင်ပေါ်မှ အချက်နှစ်ချက်ကို နှိပ်ရန် သို့မဟုတ် ကိုဩဒိနိတ် (coordinate) များ ထည့်သွင်းရန် တောင်းဆိုပါမည်။ ဖန်တီးမည့် ဖွဲ့စည်းမှု အရာဝတ္ထုသည် အဆိုပါ အချက်နှစ်ချက်ကို ချိတ်ဆက်သည့် ပုံစံဖြင့် တည်ရှိမည်။
- ဖွဲ့စည်းမှု အစိတ်အပိုင်းများသည် [Arch Components](Arch_Component.md) ၏ ပိုင်ဆိုင်မှုများနှင့် အပြုအမူများအားလုံးကို ဝေမျှထားသည်။
- ဖွဲ့စည်းမှု၏ အမြင့်၊ အကျယ်နှင့် အရှည်ကို ဖန်တီးပြီးနောက် ပြင်ဆင်နိုင်သည်။
- လက်ရှိ ကမ်းလှမ်းချက်ကို ပယ်ဖျက်ရန် **Esc** သို့မဟုတ် **Cancel** ခလုတ်ကို နှိပ်ပါ။
- ဖန်တီးပြီးနောက် Tree view တွင် ဖွဲ့စည်းမှုကို ဒဘယ်ကလစ် (double-click) နှိပ်ခြင်းဖြင့် တည်းဖြတ်မုဒ် (edit mode) ထဲသို့ ဝင်ရောက်နိုင်ပြီး ၎င်း၏ ဖြည့်စွက်မှုများနှင့် ဖြုတ်ယူမှုများကို ပြင်ဆင်နိုင်သည်။
- တည်းဖြတ်မုဒ် (edit mode) တွင် [axes systems](Arch_Axis.md) များကို ဖွဲ့စည်းမှု အရာဝတ္ထုတွင် ထည့်သွင်းနိုင်သည်။ axes system တစ်ခု ထည့်သွင်းလျှင် ဖွဲ့စည်းမှု အရာဝတ္ထုကို ထို system ၏ တစ်ခုချင်းစီသော axis ပေါ်တွင် မိတ္တူကူးပေးမည်။ axes system နှစ်ခု ထည့်သွင်းလျှင် ဖွဲ့စည်းမှုသည် အဆိုပါ နှစ်ခုသော system ၏ ဆုံမှတ် (intersection) တိုင်းတွင် မိတ္တူကူးပေးမည်။

## ပိုင်ဆိုင်မှုများ

### Data

- **Tool**: လိုအပ်လျှင် extrusion လမ်းကြောင်း (wire အမျိုးအစား မည်သည့်မျိုးမဆို) ကို ဖော်ပြသည်။ ဤပိုင်ဆိုင်မှုကို ဗလာထားပါက extrusion သည် တည့်မတ်သော ဦးတည်ရာဖြင့် Normal ပိုင်ဆိုင်မှု အတိုင်း ဖြစ်ပေါ်မည်။

- **Normal**: ဤဖွဲ့စည်းမှု၏ အခြေမြင့် မျက်နှာပြင်ကို မည်သည့် ဦးတည်ရာဖြင့် အထူဖော်ထုတ်မည် (extrude) ကို သတ်မှတ်သည်။ ဤပိုင်ဆိုင်မှုကို (0,0,0) အဖြစ် ထားလျှင် ဦးတည်ရာကို အခြေမြင့် မျက်နှာပြင်၏ ရိုးမှန် (normal) ဦးတည်ချက်အတိုင်း အလိုအလျောက် သတ်မှတ်လိမ့်မည်။

- **Face Maker**: ပရိုဖိုင်ကို ဖန်တီးရာတွင် အသုံးပြုမည့် မျက်နှာပြင်ဖန်တီးနည်းလမ်း (face creation method) ကို သတ်မှတ်သည်။ ရွေးချယ်စရာများမှာ —

    - {{Value|None}}

    - {{Value|Simple}}: ပိတ်ထားသော ဝါယာများအားလုံးမှ မျက်နှာပြင်များကို ဖန်တီးပေးသည်၊ ထပ်နေသော အပိုင်းများကို ထည့်သွင်းစဉ်းစားခြင်း မပြုဘဲ။

    - {{Value|Cheese}}: အပေါက် (hole) ပါသည့် မျက်နှာပြင်များကို ဖန်တီးပေးသည်၊ အပေါက်အတွင်း ထပ်နေသော မျက်နှာပြင်များကို ဖန်တီးခြင်း မပြုဘဲ။

    - {{Value|Bullseye}}: အပေါက်နှင့် အတွင်းပိုင်းတွင် ကျွန်းပုံ (island) ရှိနိုင်သည့် မျက်နှာပြင်များကိုပါ ဖန်တီးပေးသည်။

- **Length**: ဖွဲ့စည်းမှု၏ အရှည်ကို သတ်မှတ်သည်။ ဤတန်ဖိုးကို ဖွဲ့စည်းမှုသည် ပရိုဖိုင်အပေါ် မအခြေခံထားသော အခါတွင်သာ အသုံးပြုသည်။

- **Width**: ဖွဲ့စည်းမှု၏ အကျယ်ကို သတ်မှတ်သည်။ ဤတန်ဖိုးကို ဖွဲ့စည်းမှုသည် ပရိုဖိုင်အပေါ် မအခြေခံထားသော အခါတွင်သာ အသုံးပြုသည်။

- **Height**: ဖွဲ့စည်းမှု၏ အမြင့် သို့မဟုတ် ပရိုဖိုင်အပေါ် အခြေခံ၍ ဖြစ်ပါက extrusion ၏ အရှည်ကို သတ်မှတ်သည်။ အမြင့် မပေးထားဘဲ ဖွဲ့စည်းမှုသည် အမြင့်သတ်မှတ်ထားသော [Arch Floor](Arch_Floor.md) အရာဝတ္ထုအတွင်း ရှိပါက ဖွဲ့စည်းမှုသည် အလိုအလျောက် ထို အလွှာ (floor) ၏ အမြင့်တန်ဖိုးကို ယူမည်။

- **Nodes Offset**: centerline နှင့် nodes line အကြား လိုအပ်လျှင် offset တစ်ခုကို သတ်မှတ်ပေးနိုင်သည်။

### View

- **Nodes Type**: ဤအရာဝတ္ထု၏ ဖွဲ့စည်းမှု nodes ၏ အမျိုးအစား (linear သို့မဟုတ် area) ကို သတ်မှတ်သည်။

- **Show Nodes**: ဖွဲ့စည်းမှု nodes များကို ပြသရန် သို့မဟုတ် ဝှက်ရန် သတ်မှတ်သည်။

## Presets

Structure ကိရိယာတွင် စံသတ်မှတ်ထားသော သံပိုင်းပုံစံများ (standard steel profiles) သို့မဟုတ် precast ကွန်ကရစ် အစိတ်အပိုင်းများကို လျှင်မြန်စွာ ဖန်တီးနိုင်ရန် preset များလည်း ပါရှိသည်။

 ![](images/Arch_presets_example.jpg )  
*သံဖွဲ့စည်းမှုများအတွက် အချို့သော presets*

preset များကို ရယူရန် structure options panel မှ **Category** တစ်ခုကို ရွေးချယ်ရမည်။ ရနိုင်သော category များမှာ **Precast concrete** သို့မဟုတ် စက
