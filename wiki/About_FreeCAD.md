# <img alt="" src=images/Freecad_default.jpg  style="width:1024px;"> ဖရီးကက် (FreeCAD) အကြောင်း

**ဖရီးကက် (FreeCAD)** သည် [ဖွင့်လှစ်ရင်းမြစ် (open source)](http://en.wikipedia.org/wiki/Open_source) ပုံစံဖြင့် ထုတ်ဝေထားသော ပာရာမက်ထရစ် (parametric) 3D [**CAD**](http://en.wikipedia.org/wiki/CAD) မော်ဒယ်လারেরဖြစ်ပြီး [LGPL License](License.md) အောက်တွင် လိုင်စင်ပြုထားသည်။ ဖရီးကက်ကို သီးသန့်အားဖြင့် [စက်မှုအင်ဂျင်နီယာရင်းနှီးမှု (mechanical engineering)](http://en.wikipedia.org/wiki/Mechanical_engineering) နှင့် [ထုတ်ကုန်ဒီဇိုင်း (product design)](http://en.wikipedia.org/wiki/Product_design) အတွက် ရည်ရွယ်ထားသော်လည်း၊ အလွန်ပင် ဗဟိုသိပ္ပံဆိုင်ရာနှင့် အင်ဂျင်နီယာဆိုင်ရာ လုပ်ငန်းများအတွင်း အသုံးပြုနိုင်စွမ်းရှိပြီး ဆောက်လုပ်ရေး (architecture), Finite Element Method (FEM / အပိုင်းငယ်နည်းစနစ်), 3D ပုံနှိပ်ခြင်းနှင့် အခြားလုပ်ငန်းများအတွက်ပါ သင့်တော်သည်။

ဖရီးကက်တွင် [CATIA](https://en.wikipedia.org/wiki/CATIA), [SolidWorks](http://en.wikipedia.org/wiki/Solidworks), [Solid Edge](http://en.wikipedia.org/wiki/Solid_Edge) သို့မဟုတ် [Revit](https://en.wikipedia.org/wiki/Autodesk_Revit) ကဲ့သို့သော ကိရိယာများနှင့် ဆင်တူသော လုပ်ဆောင်ချက်များ ပါဝင်ပြီး သို့ကြောင့် [**CAD**](http://en.wikipedia.org/wiki/CAD), [**PLM**](http://en.wikipedia.org/wiki/Product_Lifecycle_Management), [**CAx**](http://en.wikipedia.org/wiki/CAx), [**CAE**](http://en.wikipedia.org/wiki/Computer-aided_engineering) နှင့် [**BIM**](https://en.wikipedia.org/wiki/Building_information_modeling) အမျိုးအစားများသို့လည်း ပါဝင်သည်။ ၎င်းသည် feature-based ပာရာမက်ထရစ် မော်ဒယ်လာတစ်ရပ်ဖြစ်ပြီး မော်ဂျူးလ်ပေါ်အခြေခံသော ဆော့ဖ်ဝဲဖွဲ့စည်းပုံကြောင့် မူလစနစ်ကို ပြင်ဆင်ရန်မလိုဘဲ အပိုဆင်ခြင်းများ ထပ်ဆောင်းထည့်သွင်းနိုင်သည်။

အခြား CAD မော်ဒယ်လားများလို တူညီစွာ ပန်းနက်ပုံစံများ (2D) ဆွဲဆောင်ရန် သို့မဟုတ် ထုတ်လုပ်ရေး attract များ ဖန်တီးရန် အသုံးပြုသည့် 2D ကွန်ပိုနင့်များစွာ ပါဝင်သည်။ သို့သော် တိုက်ရိုက် 2D ဒရော်ရွင်း (ဥပမာ [Inkscape](https://inkscape.org/) သို့မဟုတ် [AutoCAD LT](http://en.wikipedia.org/wiki/AutoCAD#AutoCAD_LT) ကဲ့သို့) သို့မဟုတ် အနုပညာ အလှဆင်ခြင်းနှင့် မက်ရှ် အယ်ဒီတင်း (ဥပမာ [Blender](https://www.blender.org/), [Maya](http://en.wikipedia.org/wiki/Maya_(software)), [3ds Max](http://en.wikipedia.org/wiki/3ds_Max), သို့မဟုတ် [Cinema 4D](http://en.wikipedia.org/wiki/CINEMA_4D)) များကို အဓိက ရည်ရွယ်ချက်မထားသော်လည်း၊ ဖရီးကက်၏ ကျယ်ပြန့်သော လိုက်လျောညီမွေ့နိုင်စွမ်းကြောင့် အခြေခံ feature များအပေါ် အခြေခံ၍ ကျယ်ပြန့်သော လုပ်ငန်းပိုင်းများတွင် အသုံးဝင်နိုင်သည်။

ဖရီးကက်သည် သိပ္ပံတွက်ချက်မှု (scientific computing) လုပ်ငန်းခွင်တွင် အသုံးများသော ဖွင့်လှစ်ရင်းမြစ် တာဝန်ခံ libraries များကို အလွန် အားထား အသုံးပြုထားသည်။ ၎င်းများထဲတွင် [Open Cascade Technology (OCCT)](http://OpenCascade.org) — အင်အားကြီး CAD kernel တစ်ခု၊ [Coin3D](https://github.com/coin3d/coin/wiki) — [Open Inventor](http://en.wikipedia.org/wiki/Open_Inventor) နှင့် ကိုက်ညီသော 3D ဂရပ်ဖစ် ဖွံ့ဖြိုးရေး ကိရိယာတစ်စု၊ နာမည်ကြီး UI ဖရိမ်းဝတ် [Qt](http://www.qt.io/) နှင့် အဆောက်အအုံ script များအတွက် လူကြိုက်များသော ဘာသာစကား [Python](http://www.python.org) တို့ ပါဝင်သည်။ ဖရီးကက်ကို အခြား ပရိုဂရမ်များမှ library အနေနှင့်လည်း အသုံးပြုနိုင်သည်။

ဖရီးကက်သည် [မီဒီယားနယ်ပယ်များပေါ်တွင်စီးဆင်းနိုင်သော (multi-platform)](http://en.wikipedia.org/wiki/Cross-platform) ဖြစ်ပြီး လက်ရှိတွင် Linux/Unix, Windows နှင့် macOS စနစ်များ ပေါ်တွင် အလားတူ အမြင်နှင့် လုပ်ဆောင်ချက်များဖြင့် ပြေးဆောင်နိုင်သည်။

ဖရီးကက်၏ အင်္ဂါရပ်များအကြောင်း ပိုမိုသိရှိလိုပါက [feature list](Feature_list.md), [latest release notes](Feature_list#Release_notes.md) နှင့် [getting started](Getting_started.md) ဆောင်းပါးများအား ရှာဖွေကြည့်ပါ၊ သို့မဟုတ် [screenshots](Screenshots.md) များကိုကြည့်ရှုနိုင်ပါသည်။

### ဖရီးကက် ပရောဂျက်အကြောင်း

ဖရီးကက် ပရောဂျက်ကို 2001 ခုနှစ်အထိ နောက်ပြန်သွားစဉ် စတင်ခဲ့ကြောင်း [သမိုင်း](History.md) စာမျက်နှာတွင် ဖော်ပြထားသည်။

ဖရီးကက်ကို [စိတ်အားထက်သန်သော ဖော်ပြသူများနှင့် အသုံးပြုသူများ၏ လူ့အသိုက်အဝန်း (community)](contributors.md) မှ ထိန်းသိမ်းဖွံ့ဖြိုးဆောင်ရွက်လာကြပြီး ကန့်ကဲမှုများ များပြားသော တင်ပြသူများ၏ ဇန်နဝါရီအစဉ်အလာဖြင့် ဖွဲ့စည်းထားသည်။ အသီးသီးသော ပါဝင်ဆောင်ရွက်သူများ၏ လက်လှမ်းများက ဖရီးကက်ကို ဖော်ဆောင်ထားသည်။ အများစုသော ဆောင်ရွက်မှုများကို အလှူရှင်များအဖြစ် တာဝန်ယူဆောင်ရွက်ကြသည်။ အမြင်များနှင့် ဆုံးဖြတ်ချက်များကို အများအားဖြင့် [ဖရီးကက် ဖိုရမ်](http://forum.freecad.org) တွင် ဆွေးနွေးရပြီး ကုဒ်များကို [GitHub ရေပိုင်ရှင် စာကြောင်း](https://github.com/FreeCAD/FreeCAD) တွင် သိမ်းဆည်း၊ မျှဝေ၊ ဆွေးနွေးနှင့် တိုးတက်စေကြသည်။ မည်သူမဆို [ပါဝင်ရန် ကြိုဆိုထားသည်](Help_FreeCAD.md)။

### FPA အကြောင်း

ဖရီးကက် ပရောဂျက်ကို အလဲမရှိ ပံ့ပိုးပေးသည့် အကျိုးမက်မဟုတ်သည့် အဖွဲ့အစည်းတစ်ခုဖြစ်သည့် [FreeCAD project association (FPA)](https://fpa.freecad.org) မှလည်း ထောက်ပံ့ထားသည်။ FPA သည် 2021 တွင် ဖရီးကက်အတွေ့အကြုံရှိသူများက စုစည်းဖန်တီးခဲ့သည့် လွတ်လပ်သော အဖွဲ့အစည်းဖြစ်ပြီး ပရောဂျက်နှင့် ၎င်း၏ လူထုကို ပံ့ပိုးရန် [လှူဒါန်းမှုများ](donate.md) နှင့် အရင်းအမြစ်များစုဆောင်းခြင်း၊ လူထုကို ကာကွယ်ရန်နှင့် အကောင်းဆုံး အခြေအနေများအောက်တွင် ဆက်လက် ဖွံ့ဖြိုးထိန်းသိမ်းနိုင်စေရန် အကူအညီပြုရန်၊ ကုမ္ပဏီများ၊ အဖွဲ့အစည်းများကဲ့သို့သော အခြားအဖွဲ့များရှေ့တွင် ပရောဂျက်ကို ကိုယ်စားပြုရန် တာဝန်ယူထားသည်။
