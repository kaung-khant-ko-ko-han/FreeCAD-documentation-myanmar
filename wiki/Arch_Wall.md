# Arch Wall (နံရံ)

## ဖော်ပြချက်

**Arch Wall** ကိရိယာသည် နံရံ (Wall) အရာဝတ္ထုကို သစ်စဉ်ဖြင့် သို့မဟုတ် မည်သည့် [shape](Part_Workbench.md)-အခြေခံ သို့မဟုတ် [mesh](Mesh_Workbench.md)-အခြေခံ အရာဝတ္ထုပေါ်တွင် တည်၍ ဆောက်လုပ်ပေးသည်။ နံရံကို မည်သည့် အခြေခံအရာဝတ္ထုမရှိဘဲလည်း ဆောက်နိုင်ပြီး ထိုအခါ အမြင့်၊ အနံနှင့် အရှည် (length, width, height) တို့ကို အသုံးပြုသည့် ကုဘစ်အရွယ်အစားအဖြစ် ပြုလုပ်မည်ဖြစ်သည်။ မြင်ပြီးသား shape ပေါ်တွင် တည်ဆောက်ပါက နံရံကို အောက်ပါ အမျိုးအစားများအရ အခြေခံနိုင်သည်-

-   **လျှောက်လမ်း 2D အရာဝတ္ထု** (လိုင်းများ၊ ဝိုင်ယာများ၊ အာခ်များ သို့မဟုတ် ပုံကြမ်း / စကစ် (Sketch) များ) အဖြစ် တည်ရှိပါက၊ အထူ (thickness)၊ ညှိချိန်ညှိ (alignment) (ညာ၊ ဘယ် သို့မဟုတ် အလယ်) နှင့် အမြင့်တို့ကို ပြင်ဆင်နိုင်မည်ဖြစ်သည်။ length ပိုင်ဆိုင်ချက်သည် သက်ရောက်မှု မရှိပါ။
-   **ထိပ်ပိုင်း မျက်နှာပြင် (flat face)** အဖြစ် တည်ရှိပါက အမြင့်ကိုသာ ပြင်ဆင်နိုင်ပြီး length နှင့် width ပိုင်ဆိုင်ချက်များ သက်ရောက်မှု မရှိပါ။ သို့သော် အခြေခံ မျက်နှာပြင်သည် ထောင်လျောက် (vertical) ဖြစ်ပါက နံရံသည် width ပိုင်ဆိုင်ချက်ကို အမြင့်ထက် အစားထိုး အသုံးပြုမည်ဖြစ်ပြီး၊ ထိုသို့ဖြင့် အာကာသဆိုင်ရာ အရာများ (space-like objects) သို့မဟုတ် mass studies များမှ နံရံများ ဆောက်နိုင်မည်ဖြစ်သည်။
-   **အစိုထည် (solid)** အဖြစ် တည်ရှိပါက length, width နှင့် height ပိုင်ဆိုင်ချက်များ သက်ရောက်မှု မရှိပါ။ နံရံသည် အောက်ခံ solid ကိုသာ ၎င်း၏ အပေါ်ယံ ပုံသဏ္ဌာန်အနေဖြင့် အသုံးပြုမည်ဖြစ်သည်။
-   **mesh** အဖြစ် တည်ရှိပါက အောက်ခံ mesh သည် ပိတ်ထားသော၊ manifold solid ဖြစ်ရမည်။

 <img alt="" src=images/Arch_Wall_example.jpg  style="width:780px;">  
*လိုင်း၊ ဝိုင်ယာ၊ မျက်နှာပြင်၊ solid နှင့် ပုံကြမ်း (Sketch) တို့မှ ဆောက်ထားသော နံရံများ*

နံရံများတွင် ပေါင်းထည့်ခြင်း (additions) သို့မဟုတ် ဖြုတ်ခြင်း (subtractions) များကိုလည်း ပိုင်ဆိုင်နိုင်သည်။ ပေါင်းထည့်ခြင်းများမှာ အခြား အရာဝတ္ထုများ၏ ပုံသဏ္ဌာန်များကို ဤ နံရံ (Wall) ၏ ပုံသဏ္ဌာန်နှင့် ပေါင်းစည်းခြင်းဖြစ်ပြီး၊ ဖြုတ်ခြင်းများသည် ဖြုတ်ခွဲခြင်းဖြစ်သည်။ ပေါင်းထည့်ခြင်းနှင့် ဖြုတ်ခြင်းကို [Arch Add](Arch_Add.md) နှင့် [Arch Remove](Arch_Remove.md) ကိရိယာများဖြင့် ထည့်/ဖယ်နိုင်သည်။ ပေါင်းထည့်ခြင်းနှင့် ဖြုတ်ခြင်းများသည် height နှင့် width ကဲ့သို့သော နံရံ၏ ပုံသတ်မှတ်ချက်များပေါ် အကျိုးသက်ရောက်မှု မရှိသေးပါ; ထိုပိုင်ဆိုင်ချက်များကို ဆက်လက် ပြောင်းလဲနိုင်သည်။ နံရံများကို ထပ်မံ အမြင့်ကို အလိုအလျောက် သတ်မှတ်နိုင်ပြီး [floors](Arch_Floor.md) ကဲ့သို့သော အထက်တန်းအရာဝတ္ထုထဲတွင် ထည့်သွင်းပါက height ကို 0 သတ်မှတ်ထားရမည်ဖြစ်ပြီး၊ ထိုနောက် နံရံသည် မိဘအရာဝတ္ထုတွင် သတ်မှတ်ထားသော အမြင့်ကို လက်ခံယူမည်ဖြစ်သည်။

နံရံများ အချို့ကို တွဲငြိမ်းချင်း ဆုံမှတ်တွင် intersection ဖြစ်စေလိုပါက ထိုနံရံများကို [floor](Arch_Floor.md) ထဲသို့ ထည့်ရမည်။

## အသုံးပြုနည်း

### သစ်စဉ်မှ နံရံဆောက်ခြင်း

1.  ကိရိယာကို ခေါ်ရန် နည်းလမ်းများ အစုံရှိသည်-
    -   **<img src="images/Arch_Wall.svg" width=16px> [Wall](Arch_Wall.md)** ခလုတ်ကို နှိပ်ပါ။
    -   မီနူးမှ **3D/BIM → <img src="images/Arch_Wall.svg" width=16px> Wall** ကို ရွေးချယ်ပါ။
    -   ကီးဘုတ် Shortcut အသုံးပြုပါ: **W** ထို့နောက် **A**။
2.  3D ကြည့်မြင်မှုတွင် ပထမနေရာကို နှိပ်ပါ၊ သို့မဟုတ် ကိုဩဒိနိတ်များကို ရိုက်ထည့်ပါ။
3.  3D ကြည့်မြင်မှုတွင် ဒုတိယနေရာကို နှိပ်ပါ၊ သို့မဟုတ် ကိုဩဒိနိတ်များကို ရိုက်ထည့်ပါ။

### ရွေးချယ်ထားသော အရာဝတ္ထုပေါ်တွင် နံရံဆောက်ခြင်း

1.  အခြေခံ ဂျီယိုမက်ထရီ အရာဝတ္ထုတစ်ခု သို့မဟုတ် အများကို (Draft object, ပုံကြမ်း / စကစ် (Sketch), စသည်) ရွေးပါ။
2.  အထက်ဖော်ပြထားသည့်အတိုင်း ကိရိယာအား ခေါ်ပါ။
3.  အမြင့် သို့မဟုတ် အနံကဲ့သို့ လိုအပ်သည့် ပိုင်ဆိုင်ချက်များကို ကိုက်ညီအောင် ပြင်ဆင်ပါ။

## ရွေးချယ်မှုများ

-   နံရံများသည် [Arch Components](Arch_Component.md) အားလုံး၏ ပုံမှန် ပိုင်ဆိုင်ချက်များနှင့် အပြုအမူများကို မျှဝေသည်။
-   နံရံ၏ အမြင့်၊ အနံနှင့် ညှိချိန်ညှိ (alignment) ကို ပုံဆွဲချိန်တွင် လုပ်ငန်းတာဝန်ပြား (Task Panel) မှတစ်ဆင့် သတ်မှတ်နိုင်သည်။
-   ရှိပြီးသား နံရံတစ်ခုကို snapping ဖြင့် အခြားနံရံသို့ ဆက်စပ်ပါက ထိုနံရံနှစ်ခုသည် တစ်ခုအဖြစ် ပေါင်းစည်းမည်။ နံရံ နှစ်ခု ပေါင်းစပ်ပုံစံသည် ၎င်းတို့၏ ပိုင်ဆိုင်ချက်များပေါ် မူတည်သည်။ အကယ်၍ ၎င်းတို့တွင် တူညီသော width၊ height နှင့် alignment ရှိ၍ Arch ဦးသတ်မှတ်ချက်များတွင် "join base sketches" ရွေးချယ်မှု ဖွင့်ထားပါက ရလဒ်နံရံသည် အပိုင်းအမျိုးမျိုး ပါဝင်သည့် ပုံကြမ်းတစ်ခုအပေါ် အခြေခံထားသည့် တစ်ခုတည်းသော object ဖြစ်မည်။ မဟုတ်လျှင် နောက်နံရံသည် ပထမနံရံသို့ addition အဖြစ် ထည့်သွင်းမည်ဖြစ်သည်။
-   ပထမချက်ကို နှိပ်ပြီးနောက် **X**, **Y** သို့မဟုတ် **Z** ကို နှိပ်၍ ဒုတိယချက်ကို သတ်မှတ်ထားသည့် ဝင်ရိုး (axis) ပေါ်တွင် ကန့်သတ်နိုင်သည်။
-   ကိုဩဒိနိတ်များကို လက်ဖြင့် ထည့်ရန် X, Y နှင့် Z တန်ဖိုးများကို အစီအစဉ်အတိုင်း ရိုက်ထည့်၍ တစ်ခုနှင့်တစ်ခုကြား **Enter** ကို နှိပ်ရုံဖြင့် ရနိုင်သည်။
-   **R** ကို နှိပ်ပါ သို့မဟုတ် **Relative** ခလုတ်ကို ဖွင့်/ပိတ် ပြုလုပ်ရန် နှိပ်ပါ။ Relative မုဒ်ဖြစ်ပါက ဒုတိယချက်၏ ကိုဩဒိနိတ်များသည် ပထမချက်နှင့် ဆက်စပ်သော ပမာဏအနေဖြင့် ရှိသည်။ မဟုတ်ပါက ၎င်းများသည် အပြ
